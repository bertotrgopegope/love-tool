## 🚀 Fitur
- **[1] Install Love** - Unduh paket cinta untuk target.
- **[2] Uninstall Love** - Hapus memori cinta (move on mode).
- **[3] Search Love** - Cari keberadaan cinta di database semesta.
- **[4] Blocked Love** - Blokir akses cinta yang toxic.
- **Custom UI** - Banner animasi Chafa dengan tema merah menyala.

## 🛠️ Instalasi
1. Update Termux dan install dependensi:
   ```bash
   pkg update && pkg upgrade -y
   pkg install python chafa -y
```

2. Install library Python:
   ```bash
   pip install colorama
   ```
3. Clone repository ini:
   ```bash
   git clone https://github.com/bertotrgopegope/love-tool.git
   cd love-tool
   ```

💻 Cara Pakai

```bash
